O primeiro passo é instalar o Node.js. Ele é o ambiente que roda o gerenciador de pacotes, o npm, e sem ele o Vue não funciona. Pra conferir se deu certo, abra o terminal e digitem node -v. Se aparecer um número de versão, está tudo certo, Se caso nao aparecer pesquise no google "Node.js" e entre no site e baixe a versao LTS a mais recomendada atualmente.

Apos isso vamos Criar o projeto Digitem npm create vue@latest. Esse é o gerador oficial: ele monta pra gente toda a estrutura com Vite e Vue 3. Ele vai fazer algumas perguntas. Podem apertar Enter nas opções padrão e dar um nome pro projeto. Depois, entrem na pasta dele com cd e rodem npm install para baixar todas dependencias necessarias para estar funcionando o seu codigo no localhost.

E Por último, digitem npm run dev. O terminal vai mostrar um link local. Abram esse link no navegador. Se apareceu a página inicial do Vue, o ambiente está pronto e funcionando.
